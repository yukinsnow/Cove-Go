# Cove-Go 0.1.15（16） · iOS 测试版 / iOS test release

**未签名 IPA，需要自行签名安装；不是 App Store / TestFlight 版本，尚未完成 iPhone 真机验证。**

**Unsigned IPA: sign it yourself before installation. Not an App Store / TestFlight release. Physical iPhone testing has not been completed.**

## 本次发布 / Highlights

- OpenClaw + DSH Remote 双后端原生远程客户端，各自隔离身份、凭据、传输与会话。
- 多 Gateway 和 SSH 接入；图片历史恢复、附件入口键盘处理、可选换行键发送。
- 会话侧栏按 Gateway 分组并按最新活动排序；运行中旋转指示；移除未读筛选和圆点。
- 产品名称 **Cove-Go**；D9 深海配色 + D14 海浪图标；中英文、日夜主题、新绘制小伙伴及上游署名。

Native dual-backend remote client for OpenClaw and DSH Remote, with isolated identities and credentials, multiple Gateways, SSH, image-history recovery, keyboard improvements, grouped/latest-activity-ordered sessions and running spinners. Uses Cove-Go branding and the approved ocean-terminal icon, with bilingual UI, light/dark themes, original companions and upstream attribution.

## 下载与安装 / Download and installation

要求 / Requirements: **iOS 15.0+, arm64**.

下载附件中的 IPA 与同名 `.sha256`，先校验，再使用可信工具（例如 iLoader）和自己的合法签名身份安装。项目不提供签名证书或共享账号。签名有效期及系统要求以工具和 Apple 规则为准。

Download the IPA and matching `.sha256`, verify before signing, then use your own signing identity with a trusted tool such as iLoader. No certificates or shared accounts are supplied. Signing expiration and OS requirements depend on the tool and Apple's rules.

```sh
shasum -a 256 -c Cove-Go-0.1.15-build16-6708c24dc8db-unsigned.ipa.sha256
```

IPA: `Cove-Go-0.1.15-build16-6708c24dc8db-unsigned.ipa`

SHA256:

```text
bbb3a39e059dbb5df7043a77c038bc767cdaf6fc716ee615cd4f1796f9017120
```

大小 / Size: **28,175,977 bytes**. Bundle ID: `io.github.yukinsnow.dshApp`.

不要为更新随意卸载旧版；本机配置可能丢失，覆盖安装和钥匙串连续性取决于签名配置。使用自己的后端和模型服务；不含后端、模型额度或 iPhone 本机 Linux 引擎。

Avoid uninstalling an existing copy just to update: settings may be lost, and update/keychain continuity depends on signing. Bring your own backend and model service. No backend, model credits or on-iPhone Linux runtime are included.

## 已验证与限制 / Checks and limitations

已验证 ZIP CRC、SHA256、产品名、版本、bundle ID、iOS 最低版本、arm64、图标、无主程序签名命令及无 provisioning profile。附件 `verification.json` 记录实际检查。Mac 独立 release 构建也成功，但不混发另一份摘要不同的二进制。

Verified ZIP CRC, SHA256, product name, version, bundle ID, minimum iOS, arm64, icons, unsigned main executable and absence of a provisioning profile. See `verification.json`. A separate Mac release build succeeded but is not mixed into these assets.

相关回归一轮 **71 tests passed**；另有 **15 项共享抽屉 golden 不匹配**与修改前基线的像素差异一致，未改基准掩盖。不是全测试通过声明，亦未做 iPhone 真机验收。

One relevant regression run passed **71 tests**. Separately, **15 shared-drawer golden mismatches** matched the pre-change baseline pixel-for-pixel; baselines were not changed to hide failures. This is not a full-suite or physical-device pass claim.

未完成 OpenClaw 原生审批 / 提问面板、语音、内联 widgets、设备能力和历史分页（当前最近 150 条）；DSH Remote 需真机端到端验收。iOS 挂起不保证后台连接，图片回退缓存不是备份。建议先用测试后端，不作唯一生产运维入口。

Not yet integrated: native OpenClaw approval/question forms, voice, inline widgets, device capabilities and history pagination (currently the latest 150 messages). DSH Remote needs physical-device end-to-end validation. Background connections are not guaranteed; image caching is not a backup. Use a test backend first.
